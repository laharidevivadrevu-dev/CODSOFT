🍰 sweet.cravings – Premium Homemade Bakery Website

📌 Project Overview

sweet.cravings is a premium homemade bakery website designed to showcase and sell freshly baked products like cakes, cookies, brownies, and chocolates.

This project focuses on creating a modern, elegant, and business-style website with a smooth user experience and working navigation system.

The website includes:
	•	Sticky navigation bar
	•	Beautiful hero section with bakery theme
	•	Product listing with images and prices
	•	Add to Cart functionality
	•	Success popup message
	•	Cart system
	•	About Us section
	•	Contact section with address
	•	Responsive and premium UI design

⸻

🎯 Project Objective

The goal of this project is to:
	•	Build a professional business-style bakery website
	•	Practice HTML, CSS, and JavaScript
	•	Implement interactive features like cart and popup messages
	•	Create a premium and clean user interface
	•	Simulate a real homemade bakery business (Bhimavaram, AP)
